# JT workday atlas

HTML 목업(식대정산 · 라이선스 · 팀 예산 등)을 기반으로 만든 Vite + React 웹 앱입니다.

## 실행

```bash
cd web
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

## 주요 기능

- **홈**: 오늘 업무, 식대 안내, 식당/버킷리스트 요약
- **식대 청구**: 영수증 금액 · 지역화폐 10% 할인 · 1,000원 단위 반올림 미리보기 후 제출
- **식대 현황 / 운영**: 청구 목록 조회, 승인·보완 처리
- **라이선스**: 개요, 구독 알림, 카탈로그, 갱신 검토, 신규 등록
- **팀 예산 / 캘린더 / 식당 / 버킷리스트 / 운영 관리**

데이터는 브라우저 메모리(목 데이터)로 동작하며, 새로고침 시 초기화됩니다.
